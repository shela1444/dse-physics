📌 1. Scalar vs Vector Quantities

Scalar: magnitude only. Examples: distance, speed, mass, time, energy, temperature.
Vector: magnitude + direction. Examples: displacement, velocity, acceleration, force, momentum.
QuantityTypeRemarks
DistanceScalarTotal path length
DisplacementVectorStraight‑line separation from start to end
SpeedScalardistance/time
VelocityVectordisplacement/time
AccelerationVectorrate of change of velocity
✅ Past paper common: “Which is not a vector?” – potential energy, work, kinetic energy are scalars. (e.g. 1991/II/1, 1997/II/4, 2000/II/1)

📏 2. Distance, Displacement & Average Speed/Velocity

Average speed = total distance / total time

Average velocity = total displacement / total time

Example (Class Work 2 / 1999 CE Q1): A man walks A→B (120 m, 30 s) then runs backwards B→C (100 m, 20 s).
Total distance = 120+100 = 220 m, total time = 50 s → average speed = 4.4 m/s.
Displacement: from A to C = 120 – 100 = 20 m → average velocity = 20/50 = 0.4 m/s.
⚠️ Distinguish between average speed (scalar) and average velocity (vector). Many students forget to compute net displacement.

📈 3. Motion Graphs – s‑t, v‑t, a‑t

3.1 Displacement–time (s‑t) graph

  • Slope = velocity (steeper → faster)
  • Horizontal line → at rest
  • Intersection → objects meet (same position)
  • Curved line → changing velocity (acceleration)

3.2 Velocity–time (v‑t) graph

  • Slope = acceleration
  • Area under graph = displacement (signed area = net displacement; total area = distance)
  • Crossing time axis → direction change
  • Intersection of two v‑t graphs → equal velocities (not meeting point)

3.3 Acceleration–time (a‑t) graph

  • Area under a‑t graph = change in velocity
  • Constant acceleration → horizontal line
Typical transformation: s‑t (parabola) → v‑t (straight line) → a‑t (horizontal). Uniform acceleration → s ∝ t².

Worked Example (Class Work 14 / 2011 CE style)

From v‑t graph: area under graph gives displacement. For a dog: 0–1 s acceleration = slope = (5–0)/1 = 5 m/s²; 1–4.5 s constant velocity; 4.5–5.5 s deceleration. Distance = area = (½×1×5) + (3.5×5) + (½×1×5) = 2.5 + 17.5 + 2.5 = 22.5 m.

🧮 4. Equations of Uniformly Accelerated Motion (suvat)

v = u + a t

s = u t + ½ a t²

v² = u² + 2 a s

s = ½ (u + v) t

u = initial velocity, v = final velocity, a = acceleration, t = time, s = displacement

✅ Always use consistent sign convention. For upward positive, a = –g (if g = 9.81 m/s² downward).
📌 Common questions: stopping distance (v=0), take‑off distance, free fall.

Example (Class Work 25 / 2003 CE Q4)

Plane starts from rest, a = 2 m/s², take‑off speed = 60 m/s. Find minimum distance.
v² = u² + 2as → 60² = 0 + 2×2×s → s = 3600/4 = 900 m.

Example (Class Work 24 / 2007 CE Q1)

Bicycle 100 m in 9.77 s from rest → s = ½ a t² → 100 = ½ a (9.77)² → a ≈ 2.10 m/s².

⬇️ 5. Vertical Motion under Gravity

Near Earth’s surface, all objects fall with constant acceleration g = 9.81 m/s² downward (air resistance neglected).

  • Acceleration is constant throughout the motion (upward and downward).
  • At highest point: v = 0, a = –g (still 9.81 m/s² downward).
  • Time up = time down for same level.
  • Return speed = initial speed (magnitude), opposite direction.
  • Motion independent of mass (Galileo’s experiment).

Typical past paper: free fall from rest

For free fall from rest: s = ½ g t², v = g t, v² = 2 g s.

Example (Class Work 31 / 2008 CE Q1)

Fish jumps to max height 0.5 m. Speed at launch? v² = u² + 2as, at top v=0 → 0 = u² – 2g(0.5) → u = √(9.81) ≈ 3.13 m/s.

Example (Class Work 33 / 2013 DSE Q8)

Particle released from rest, XY : YZ = 9:16. Let XY = 9k, YZ = 16k, total 25k. Time for XY: 9k = ½ g t₁² → t₁ = √(18k/g). Time for XZ: 25k = ½ g (t₁+t₂)² → t₁+t₂ = √(50k/g). Thus t₂ = √(50k/g) – √(18k/g). Ratio t₁:t₂ = √18 : (√50 – √18) = 3√2 : (5√2 – 3√2) = 3:2. So t₁:t₂ = 3:2.

⚠️ Common mistake: saying acceleration is zero at top. For projectile under gravity, acceleration is always g downward.

🎯 7. Additional Problem-Solving Strategies

Reaction time + braking distance: total stopping distance = thinking distance (constant speed × reaction time) + braking distance (using v² = u² + 2as).
📌 For two‑part journeys (e.g. 2005/II/1‑2): first part constant speed (reaction), second part uniform deceleration. Read graph carefully.

Example (Class Work 15 / 1992 CE style)

Car initial 10 m/s, reaction time 0.8 s → thinking distance = 10×0.8 = 8 m. Braking to rest in 1.7 s (from graph) → deceleration a = (0–10)/1.7 = –5.88 m/s², braking distance = area under v‑t triangle = ½×10×1.7 = 8.5 m. Total = 16.5 m. If obstacle 20 m away → safe.

🧪 8. Experimental Determination of g

  • Free‑fall apparatus / ticker‑timer / light gates.
  • Measure distance travelled in successive equal time intervals: distances increase as 1:3:5:… for uniform acceleration from rest.
  • v‑t graph slope → g ≈ 9.81 m/s².

📖 9. Quick Formula Reference Card

Uniform acceleration:
v = u + at
s = ut + ½at²
v² = u² + 2as
s = ½(u+v)t

Free fall (from rest):
s = ½gt², v = gt, v² = 2gs

Graph links:
Slope(s‑t) = v, Slope(v‑t) = a, Area(v‑t) = s, Area(a‑t) = Δv

⚠️ 10. Common Pitfalls in Exams

  • Confusing distance with displacement (especially in vector questions).
  • Forgetting sign convention in vertical motion (upward positive → a = –g).
  • Assuming v‑t intersection means meeting – it only means same velocity.
  • Using wrong suvat equation when acceleration not constant.
  • Not converting units (km/h to m/s – divide by 3.6).
✅ Exam strategy for Paper 1A (MC): Sketch graphs, label axes, use area/slope shortcuts. For Section B, show clear steps, define positive direction, and state formulas.

📌 11. Selected Past Paper Questions (with brief solutions)

Q1 (1990/II/1)

v² vs s graph: slope = 2a → from graph, slope = (16–0)/(4–0)=4 → 2a=4 → a=2 m/s² → Answer C.

Q2 (1992/II/4)

Velocity‑time graph for stone thrown upwards, reaches sea after 18 s. Height of cliff = area under v‑t graph (consider sign). Typically area above axis minus area below = net displacement = –height of cliff (downward). Use graph values to compute.

Q3 (2000/II/3)

Racing car: 0 to 100 km/h in 3.2 s. Convert 100 km/h = 27.78 m/s → a = (27.78)/3.2 ≈ 8.68 m/s² → Answer B.

Q4 (2003/II/3)

Car on circular path, radius 30 m, returns to A after 15 s. Distance = circumference = 2π×30 = 188.5 m → average speed = 188.5/15 ≈ 12.6 m/s → Answer D.

Q5 (2007/II/33)

v² vs s graph: slope = 2a → from graph, slope = (4–0)/(2–0)=2 → 2a=2 → a=1 m/s² → Answer B.

Q6 (2012 DSE 1A Q7)

Bouncing ball (perfectly elastic): velocity‑time graph alternates between positive and negative slopes (linear segments), displacement‑time graph is parabolic arches. Correct option: (2) and (4) (v‑t with constant slopes, s‑t symmetric).
